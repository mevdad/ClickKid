# 🥚 Яйцо с сюрпризом

Браузерная игра для малышей на [Three.js](https://threejs.org/): открываем шоколадное
яйцо с игрушкой внутри. Кликами снимаем фольгу, разбиваем шоколад, откручиваем
крышку контейнера — и оттуда выпрыгивает фигурка.

## Как играть

1. **Фольга** — 8 кликов отрывают неровные цветные пятна фольги, будто её
   срывают руками, а не режут дольками.
2. **Шоколад** — 14 кликов откалывают скорлупу такими же хаотичными
   кусочками; сквозь дырки сразу виден жёлтый контейнер внутри.
3. **Контейнер** — 2 клика прокручивают крышку, третий её открывает.
4. **Сюрприз** — игрушка выезжает наружу под фанфары, конфетти и салют.

И фольга, и шоколад устроены одинаково: цельная гладкая оболочка без единого
шва, пока её не тронули, случайно поделена на неровные кусочки. Клик работает
в любом месте экрана (малышам сложно попадать точно) — он всегда откалывает
ближайший к текущему повороту целый кусочек, а не случайный через всё яйцо.
Яйцо доворачивается к нему на минимальный угол, а сам отломанный кусочек летит
и падает независимо от этого поворота — момент откола всегда хорошо виден.
Пробел и Enter дублируют клик. Кнопка 🔊 в углу выключает звук.

Сейчас в игре три фигурки: **Пчёлка**, **Медвежонок** и **Поросёнок** — выпадают
случайно, но одна и та же не повторяется два раза подряд.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка и локальный просмотр собранной версии:

```bash
npm run build
npm run preview
```

Для отладки можно зафиксировать фигурку через параметр в адресе:
`?figure=bee`, `?figure=bear`, `?figure=piglet`.

## Деплой

Workflow `.github/workflows/deploy.yml` собирает игру и публикует её на GitHub Pages
при каждом пуше в `main`. Пулл-реквесты только собираются, без публикации.

Один раз нужно включить Pages в настройках репозитория:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.

После этого игра будет доступна по адресу `https://<owner>.github.io/<repo>/`.
В `vite.config.js` стоит `base: './'`, поэтому сборка работает и в подпапке,
и при открытии с любого другого хостинга статики.

## Структура

```
src/
  main.js          — точка входа и цикл отрисовки
  scene.js         — рендерер, камера, свет, фон
  game.js          — состояния игры и обработка кликов
  ui.js            — подсказки, прогресс, карточки
  audio.js         — звуки (синтезируются в WebAudio, файлов нет)
  confetti.js      — бумажное конфетти на финале
  fireworks.js     — салют (фейерверк) на финале
  utils.js         — покадровые анимации и сглаживания
  egg/
    eggShape.js    — общий профиль яйца
    shellPieces.js — общая механика хаотичных кусочков (сетка, гладкие
                     нормали, «выращивание» пятен, независимый полёт)
    foil.js        — слой фольги
    chocolate.js   — слой шоколада
    capsule.js     — контейнер с крышкой
  figures/
    index.js       — список игрушек и загрузка своих моделей
    parts.js       — общие детали (глаза, лапки, улыбки)
    bee.js / bear.js / piglet.js
```

## Про модели и лицензии

Фигурки собраны прямо в коде из примитивов Three.js. Так сделано намеренно:
бесплатные модели известных персонажей в интернете почти все фанатские, сделаны
по диснеевским версиям и распространяются с пометкой «только для личного
использования». Диснеевский образ Винни-Пуха до сих пор под охраной — в
общественное достояние перешли только оригинальные книжные персонажи
А. Милна 1926 года, без красной футболки. Класть такие файлы в репозиторий
нельзя, поэтому медвежонок и поросёнок здесь собственные.

Если хотите подставить свои модели `.glb` — смотрите
[`public/models/README.md`](public/models/README.md): достаточно положить файл
в папку и прописать его в `manifest.json`, код сам подхватит, отмасштабирует
и проиграет анимацию.
