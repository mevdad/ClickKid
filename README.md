# 🥚 Яйцо с сюрпризом

Браузерная игра для малышей на [Three.js](https://threejs.org/): открываем шоколадное
яйцо с игрушкой внутри. Кликами снимаем фольгу, разбиваем шоколад, откручиваем
крышку контейнера — и оттуда выпрыгивает фигурка.

## Как играть

1. **Фольга** — яйцо целиком завёрнуто в блестящую фольгу, заранее строго
   поделённую на 8 ярких цветных участков (настоящая диаграмма Вороного —
   вся поверхность закрашена, никаких зазоров или бледного фона между
   цветами), с рваными органическими границами между ними вместо прямых
   линий. Клик срывает целиком тот участок, что сейчас смотрит на игрока, —
   точно по его собственной границе, как будто фольгу реально сдирают.
   Как только участок сорван, яйцо само доворачивается фронтальной стороной
   к ближайшему ещё целому — никогда не приходится смотреть на пустое место,
   гадая, где искать оставшуюся фольгу.
2. **Шоколад** — под фольгой цельная гладкая шоколадная скорлупа без единого
   шва, заранее поделённая на 14 округлых кусков. Граница каждого куска —
   не растровая маска, а гладкий контур: строится трассировкой лучей из
   собственной точки-очага куска (диаграмма Вороного по настоящему
   расстоянию на поверхности яйца звёздчата относительно своего очага, так
   что вдоль любого направления есть ровно одна точка границы) и сглажена
   по Чайкину — поэтому край получается по-настоящему плавной кривой при
   любом приближении, без «квадратиков» и без оторванных островков. Клик в
   любом месте экрана «откусывает» намеченный кусок целиком, ровно по этой
   границе, как будто его действительно откусили, — а яйцо так же само
   доворачивается к следующему; сквозь дырки сразу виден жёлтый контейнер
   внутри.
3. **Контейнер** — 2 клика прокручивают крышку, третий её открывает.
4. **Сюрприз** — игрушка выезжает наружу под фанфары, конфетти и салют.

Оба слоя строятся по одной и той же плотной случайной сетке точек
поверхности яйца (только с разным масштабом радиуса) — форма получается
идеально гладкой без единого треугольника в силуэте, и фольга гарантированно
всегда строго снаружи шоколада, никогда не «тонет» в нём. И фольга, и
шоколад — цельные меши, которые не ломаются на отдельные объекты, а
стираются как текстура (альфа-маска), поэтому границы кусков не привязаны
к густоте сетки самого яйца. Пробел и Enter дублируют клик. Кнопка 🔊 в
углу выключает звук.

Сейчас в игре пять фигурок: **Пчёлка**, **Медвежонок**, **Поросёнок**,
**Тигрёнок** и **Малыш** — выпадают
случайно, но одна и та же не повторяется два раза подряд.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка и локальный просмотр собранной версии:

```bash
npm run build
npm run preview
```

Для отладки можно зафиксировать фигурку через параметр в адресе:
`?figure=bee`, `?figure=bear`, `?figure=piglet`.

## Деплой

Workflow `.github/workflows/deploy.yml` собирает игру и публикует её на GitHub Pages
при каждом пуше в `main`. Пулл-реквесты только собираются, без публикации.

Один раз нужно включить Pages в настройках репозитория:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.

После этого игра будет доступна по адресу `https://<owner>.github.io/<repo>/`.
В `vite.config.js` стоит `base: './'`, поэтому сборка работает и в подпапке,
и при открытии с любого другого хостинга статики.

## Структура

```
src/
  main.js          — точка входа и цикл отрисовки
  scene.js         — рендерер, камера, свет, фон
  game.js          — состояния игры и обработка кликов
  ui.js            — подсказки, прогресс, карточки
  audio.js         — звуки (синтезируются в WebAudio, файлов нет)
  confetti.js      — бумажное конфетти на финале
  fireworks.js     — салют (фейерверк) на финале
  utils.js         — покадровые анимации и сглаживания
  egg/
    eggShape.js    — общий профиль яйца
    shellPieces.js — общая механика поверхности (триангуляция Делоне,
                     гладкие аналитические нормали, цельный меш-оболочка
                     для обоих слоёв)
    foil.js        — слой фольги: цельная оболочка, поделённая на цветные
                     участки по диаграмме Вороного, стирается как текстура
    chocolate.js   — слой шоколада: цельная оболочка, поделённая на округлые
                     куски по диаграмме Вороного (по реальному расстоянию
                     на поверхности), «откусывается» стиранием текстуры
    capsule.js     — контейнер с крышкой
  figures/
    index.js       — список игрушек и загрузка своих моделей
    parts.js       — общие детали (глаза, лапки, улыбки)
    bee.js / bear.js / piglet.js / tiger.js / baby.js
```

## Про модели и лицензии

Пчёлка, медвежонок и поросёнок собраны прямо в коде из примитивов Three.js.
Так сделано намеренно: бесплатные модели известных персонажей в интернете
почти все фанатские, сделаны по диснеевским версиям и распространяются
с пометкой «только для личного использования». Диснеевский образ
Винни-Пуха до сих пор под охраной — в общественное достояние перешли
только оригинальные книжные персонажи А. Милна 1926 года, без красной
футболки. Класть такие файлы в репозиторий нельзя.

Тигрёнок и Малыш — настоящие 3D-модели (`public/models/tiger.glb`,
`public/models/baby.glb`), загружаются через `GLTFLoader`; если по
какой-то причине файл не загрузится, код молча подставит процедурную
фигурку (`figures/tiger.js` / `figures/baby.js`).

Если хотите подставить свои модели `.glb` — смотрите
[`public/models/README.md`](public/models/README.md): достаточно положить файл
в папку и прописать его в `manifest.json`, код сам подхватит, отмасштабирует
и проиграет анимацию.
