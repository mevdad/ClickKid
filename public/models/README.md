# Свои модели игрушек

Фигурки в игре собраны прямо в коде (`src/figures/`) из простых примитивов —
это значит, что игра не зависит от сторонних файлов и лицензий.

Если хотите подставить свою модель:

1. Положите файл `.glb` (или `.gltf` со всеми зависимостями) в эту папку.
2. Пропишите его в `manifest.json`:

```json
{
  "bee": { "file": "bee.glb", "name": "Пчёлка" },
  "bear": { "file": "bear.glb", "name": "Медвежонок" },
  "piglet": { "file": "piglet.glb", "name": "Поросёнок" }
}
```

Ключи — это `id` из `src/figures/index.js`. Модель автоматически
масштабируется под размер контейнера и ставится на «пол». Если в файле есть
анимация, проигрывается первая из них.

Если модель не загрузится, игра молча возьмёт встроенную фигурку.

## О лицензиях

Большинство бесплатных моделей известных персонажей в интернете — фанатские,
сделаны по диснеевским версиям и распространяются с пометкой «только для
личного использования». Диснеевский образ Винни-Пуха всё ещё под охраной
(в общественное достояние перешли только оригинальные книжные персонажи
А. Милна 1926 года, без красной футболки). Поэтому в репозитории таких файлов
нет — добавляйте их себе сами и проверяйте условия лицензии.
